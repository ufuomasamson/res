# Regis Logistics PTE Ltd

Premium corporate website for Regis Logistics — petroleum storage, terminal operations, pipeline transport, and global energy logistics.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Cinematic homepage experience
- `/about` — Mission, vision, values, timeline
- `/services` — Service hub
- `/services/liquid-storage`
- `/services/pipeline-transport`
- `/services/logistics-shipping`
- `/sustainability`
- `/terminal-operations`
- `/contact`
